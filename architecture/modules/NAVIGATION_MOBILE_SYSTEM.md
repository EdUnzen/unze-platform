# NAVIGATION & MOBILE SYSTEM

# Grundprinzip

UNZE wird primär als Mobile-First Plattform entwickelt.

Die Navigation muss:
- einfach
- schnell
- modern
- intuitiv

sein.

---

# Hauptnavigation

Die Hauptnavigation befindet sich unten.

## Navigationselemente

- Home
- Discover
- Plus Button
- Favoriten
- Profil

---

# Plus-Button-System

Der mittlere Plus-Button ist das zentrale Creator-Element der Plattform.

Der Button:
- ist grün
- rund
- hervorgehoben
- animiert
- zentral platziert

---

# Plus-Menü

Beim Klick öffnet sich:

- Beitrag erstellen
- Community erstellen
- Dashboard öffnen

Animation:
- weich
- hochwertig
- modern
- mobile optimiert

---

# Mobile First Prinzip

Die Plattform wird:
- primär für Smartphones entwickelt
- touchfreundlich gestaltet
- card-basiert aufgebaut

Desktop ist sekundär.

---

# Card-System

Die Plattform verwendet:
- große Karten
- moderne Container
- weiche Schatten
- moderne Übergänge
- hochwertige Animationen

---

# Touch-Prinzip

Buttons und Karten sollen:
- groß genug
- leicht klickbar
- modern animiert

sein.

---

# Discover-Navigation

Discover besitzt:
- Community-Bereich
- Feed-Bereich
- Trend-Bereich
- Vorschläge

Nutzer sollen einfach zwischen Bereichen wechseln können.

---

# Community-Navigation

Communitys besitzen:
- Hauptübersicht
- Beiträge
- Mitglieder
- Infos
- Dashboard-Bereiche

---

# Dashboard-Navigation

Creator-Dashboards sollen:
- modular
- übersichtlich
- mobilfreundlich

sein.

Keine:
- komplizierten Adminpanels
- technischen Monster-Menüs

---

# Designprinzip

Navigation soll:
- modern
- hochwertig
- emotional
- flüssig

wirken.

Keine:
- überladenen Menüs
- chaotischen Strukturen
- komplizierten UX-Systeme

---

# Design-Richtung

Inspiration:
- Apple UI
- TikTok Navigation
- Discord Struktur
- Circle UX
- moderne SaaS Apps

---

# Farbprinzip

Primärfarbe:
- modernes Grün

Sekundär:
- Weiß
- Dunkelgrau
- Schwarz

Zusätzlich:
- Blur
- Glass-Effekte
- Soft Shadows

---

# Ziel

Die Navigation soll:
- modern wirken
- Creator stärken
- Communities hervorheben
- Discover vereinfachen
- Mobile perfekt unterstützen

ohne kompliziert zu wirken.
