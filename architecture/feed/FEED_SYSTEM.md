# FEED SYSTEM

# Grundprinzip

Der Feed dient:
- Discoverbarkeit
- Community-Wachstum
- Interaktion
- Aktivität
- Creator-Sichtbarkeit

UNZE ist kein klassisches Social Network.

Der Feed unterstützt Communities,
nicht reine Selbstdarstellung.

---

# Feed-Typen

## Community Feed
Beiträge aus:
- Communities
- Gruppen
- gefolgten Creatorn

---

## Discover Feed
Gemischte Inhalte basierend auf:
- Interessen
- Interaktionen
- Trends
- Community-Relevanz
- Aktivität

---

## Persönlicher Feed
Beiträge von:
- gefolgten Nutzern
- Communities
- Favoriten

---

# Beitragstypen

Mögliche Beiträge:
- Text
- Bilder
- Community-Anfragen
- Umfragen
- Event-Ankündigungen
- Creator-Posts
- Community-Updates

---

# Kommentare

Kommentare sollen:
- einfach
- modern
- übersichtlich

sein.

Keine:
- riesigen verschachtelten Foren
- komplizierten Kommentarstrukturen

---

# Sichtbarkeit

Beiträge werden NICHT an alle Nutzer ausgespielt.

Sichtbarkeit basiert auf:
- Interessen
- Follows
- Communities
- Aktivität
- Relevanz

---

# Community-Fokus

Beiträge sollen hauptsächlich:
- Communitys stärken
- Diskussionen fördern
- Gruppen aufbauen
- Nutzer verbinden

---

# Feed-Ziele

Der Feed soll:
- lebendig
- modern
- interessant
- hochwertig

wirken.

Nicht:
- chaotisch
- überladen
- toxisch
- rein algorithmisch manipulativ

---

# Creator-System

Creator können:
- Beiträge hervorheben
- Community-Posts erstellen
- Ankündigungen posten
- Community-Feeds steuern

---

# Discover-Prinzip

Discover soll:
- abwechslungsreich
- hochwertig
- relevant

sein.

Mischung aus:
- Communities
- Feed-Posts
- Trends
- Vorschlägen

---

# Designprinzip

Feed-System:
- Card-basiert
- Mobile First
- moderne Animationen
- weiche Übergänge
- hochwertige UI

Design-Inspiration:
- TikTok Discover
- Apple UI
- Discord Struktur
- Circle UX

---

# Ziel

Das Feed-System soll Communities wachsen lassen,
ohne ein chaotisches klassisches Social Network zu werden.
