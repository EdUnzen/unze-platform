# UNZE — SYSTEM ARCHITECTURE

# Grundprinzip

UNZE ist eine modulare Community- und Creator-Plattform.

Die Plattform dient als:
- Community-Verzeichnis
- Creator-System
- Discover-Plattform
- Identitäts-System
- Verwaltungsplattform

Kommunikation findet hauptsächlich auf externen Plattformen statt.

---

# Kernsysteme

## Community-System
Verwaltet:
- Communities
- Gruppen
- Plattformtypen
- Community-Seiten
- Community-Dashboard
- Mitglieder
- Rollen
- Badges

---

## Feed-System
Verwaltet:
- Beiträge
- Kommentare
- Likes
- Discoverbarkeit
- Trends
- Community-Posts

---

## Discover-System
Verwaltet:
- Community Discover
- Feed Discover
- Trends
- Vorschläge
- Interessenlogik

---

## Creator-System
Verwaltet:
- Creator Profile
- Creator Communities
- Creator Rechte
- Creator Dashboard
- Monetarisierung

---

## Rollen-System

Rollen:
- Creator
- Admin
- Moderator
- Mitglied

Nur Creator besitzt:
- Hauptrechte
- Löschrechte
- Eigentumsrechte
