# UNZE — MASTER CONTEXT

## Projektname
UNZE — Universelles Netzwerk

---

# Kernidee

UNZE ist eine mobile-first Community- und Creator-Plattform
für Communities, Gruppen, Netzwerke und digitale Organisationen.

Die Plattform verbindet:
- Community-Systeme
- Gruppen
- Creator
- Feed-Systeme
- Discover-Systeme
- Mitgliedschaften
- Verifizierungen
- Badges
- Monetarisierung
- externe Plattformen

UNZE ist kein klassisches soziales Netzwerk.

UNZE ist die Meta-Ebene für Communities.

---

# Plattform-Philosophie

Externe Plattformen bleiben Kommunikationsplattformen:
- WhatsApp
- Discord
- Telegram
- Facebook
- andere Plattformen

UNZE dient als:
- Zugangssystem
- Community-Verzeichnis
- Discover-Plattform
- Creator-System
- Verwaltungsplattform
- Identitäts- und Reputationssystem

## Hauptnavigation Mobile

- Home
- Discover

---

# Plus-Button-System

Mittlerer Floating Action Button.

Öffnet:
- Beitrag erstellen
- Community erstellen
- Dashboard öffnen

Der Button ist:
- grün
- modern
- animiert
- zentraler Creator-Einstieg

---

# Discover-System

Discover besitzt mehrere Bereiche:
- Communities
- Feed
- Trends
- Vorschläge

Feed ist:
- algorithmisch gemischt
- nicht chaotisch
- community-zentriert

Posts von Usern werden hauptsächlich:
- Followern
- interessierten Nutzern
- passenden Communities

angezeigt.

---

# Community-System

Communities besitzen:
- Titel
- Beschreibung
- Plattform-Typ
- Tags
- Badges
- Bewertungen
- Creator
- Rollen
- Mitgliederzahlen
- Discoverbarkeit

---

# Rollen-System

Rollen:
- Creator
- Admin
- Moderator
- Mitglied

Nur Creator kann:

- Eigentümer übertragen
- Hauptrechte verwalten

---

# Badge-System

- Badges entziehen

- eventbezogen

# Feed-System

- Abstimmungen erstellen

Feed dient:
- Community-Wachstum
- Interaktion
- Discoverbarkeit

# Rechtliche Struktur

Community-Inhalte und Gruppenverantwortung liegen beim jeweiligen Betreiber.

UNZE stellt:
- Plattform
- Infrastruktur
- Verwaltungssysteme

bereit.

Keine Verantwortung für:
- Community-Inhalte
- externe Gruppeninhalte
- Creator-Aussagen

liegt bei der Plattform selbst.
