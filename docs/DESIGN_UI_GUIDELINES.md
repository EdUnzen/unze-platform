# DESIGN & UI GUIDELINES

# Grundprinzip

UNZE verwendet ein modernes,
hochwertiges und Mobile-First Designsystem.

Die Plattform soll:
- modern
- ruhig
- hochwertig
- emotional
- communityorientiert

wirken.

---

# Ziel

Das UI soll:
- Communities hervorheben
- Creator stärken
- Discover angenehm machen
- modern wirken
- hochwertige UX erzeugen

Keine:
- chaotischen Social-Media-Interfaces
- überladenen Menüs
- aggressiven Aufmerksamkeitssysteme

---

# Design-Richtung

Inspiration:
- Apple UI
- Discord Struktur
- Circle UX
- modernes TikTok Discover
- Notion Modularität
- moderne SaaS Interfaces

---

# Mobile First

UNZE wird primär:
- für Smartphones
- für Touch-Bedienung
- für PWA-Nutzung

entwickelt.

Desktop ist sekundär.

---

# Farbprinzip

## Primärfarbe
- modernes Grün

## Sekundärfarben
- Weiß
- Dunkelgrau
- Schwarz

## Zusätzliche Effekte
- Blur
- Glass-Effekte
- Soft Shadows
- leichte Transparenzen

---

# Card-System

Die Plattform basiert auf:
- modernen Karten
- großen Touchflächen
- klaren Containern
- weichen Übergängen

---

# Animationen

Animationen sollen:
- weich
- modern
- performant
- hochwertig

wirken.

Keine:
- übertriebenen Animationen
- langsamen Effekte
- chaotischen Übergänge

---

# Typografie

Das UI soll:
- klar
- modern
- gut lesbar
- hochwertig

wirken.

Keine:
- überladenen Schriftarten
- chaotischen Textblöcke

---

# Navigation

Navigation soll:
- einfach
- intuitiv
- schnell erreichbar

sein.

Hauptnavigation:
- Home
- Discover
- Plus Button
- Favoriten
- Profil

---

# Plus-Button

Der Plus-Button ist:
- zentrales Creator-Element
- grün
- hervorgehoben
- animiert
- hochwertig

Beim Klick öffnet sich:
- Beitrag erstellen
- Community erstellen
- Dashboard öffnen

---

# Discover-System

Discover soll:
- lebendig
- modern
- hochwertig
- ruhig

wirken.

Mischung aus:
- Communities
- Feed
- Trends
- Empfehlungen

---

# Community-Design

Communitys sollen:
- individuell
- hochwertig
- modern
- visuell klar

wirken.

Keine:
- chaotischen Layouts
- unübersichtlichen Menüs
- überladenen Seiten

---

# Creator-Dashboard

Dashboard soll:
- modular
- mobilfreundlich
- modern
- professionell

sein.

Keine:
- komplizierten Adminpanels
- technischen Monster-Interfaces

---

# Profil-Design

Profile sollen:
- Persönlichkeit zeigen
- Community-Zugehörigkeit zeigen
- hochwertig wirken

ohne toxische Social-Media-Optik.

---

# Plattform-Icons

Plattformen erhalten:
- eigene Icons
- klare visuelle Kennzeichnung
- hochwertige Darstellung

---

# Qualitätsprinzip

Neue UI-Komponenten müssen:
- modular
- konsistent
- touchfreundlich
- performant

sein.

---

# Zukunftsprinzip

Spätere Erweiterungen:
- Theme-System
- Creator-Layouts
- Community-Themes
- dynamische Farbsysteme
- modulare UI-Pakete

---

# Ziel

Das Designsystem soll UNZE
zu einer modernen hochwertigen Community-Plattform machen,
die sich emotional und visuell stark von klassischen Social Networks unterscheidet.
