# DEPLOYMENT & INFRASTRUCTURE

Geplante Hauptsysteme:
- GitHub
- Vercel
- Supabase
- Cursor

---

# Ziel

Die Infrastruktur soll:
- stabil
- skalierbar
- sicher
- automatisierbar

sein.

- vermischten Systeme
- unklaren Zuständigkeiten
